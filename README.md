# Shinsegae Attendance

신세계백화점 앱의 리워드 캘린더 출석을 안드로이드 휴대폰에서 예약 실행하는 개인용 APK입니다.

## 다운로드

- [APK v4.9.35 바로 다운로드](https://github.com/seojunpark2-dotcom/Shinsegae-Attendance/raw/refs/heads/account/releases/shinsegae-auto-attendance-v4.9.35.apk)
- [ZIP v4.9.35 바로 다운로드](https://github.com/seojunpark2-dotcom/Shinsegae-Attendance/raw/refs/heads/account/releases/shinsegae-auto-attendance-v4.9.35.zip) — 브라우저가 APK를 차단할 때 사용

저장소가 비공개인 경우 GitHub에 로그인한 상태에서 링크를 열어야 합니다. ZIP을 받은 경우 압축을 풀고 안의 APK를 설치하세요. 이 버전은 `account` 브랜치에서만 배포하며 `main`은 변경하지 않습니다.

## 설정

1. APK를 휴대폰에 설치합니다.
2. 앱을 열고 알림 권한을 허용합니다.
3. **접근성 권한 열기**에서 `신세계 자동 출석`을 켭니다.
4. **알람 권한 열기**에서 정확한 알람을 허용합니다.
5. 화면 위쪽의 **시간 변경**으로 예약 시각을 정하고, 필요하면 **프라이버시 커튼**을 설정합니다.
6. **매일 자동 출석** 스위치를 켠 뒤 **지금 수동 실행**으로 확인합니다.
7. 결과 알림이 표시되지 않으면 **결과 팝업 알림 설정**에서 알림을 허용하고 팝업 표시를 켭니다. Android 13 이상에서는 앱의 알림 권한도 허용해야 합니다.
8. 메인 화면의 **자동 출석 계정**에서 아이디·비밀번호를 하나씩 저장합니다. 저장된 아이디와 순번이 목록에 표시되며, 같은 아이디를 다시 저장하면 순서를 유지한 채 비밀번호가 변경됩니다. 이전 버전에서 저장한 단일 계정은 첫 번째 계정으로 이전됩니다.

## 여러 계정 순차 출석

계정을 저장하면 예약 또는 수동 실행 시 목록 순서대로 처리합니다. 첫 계정은 메인 화면의 로그인 진입부터 시작하며, 이미 로그아웃 상태라면 설정 화면을 방문하지 않습니다. 전날 마지막 계정 등이 남아 있어 로그인된 마이페이지가 나타나는 경우에만 로그아웃합니다. 신세계 앱 메인 화면의 오른쪽 아래 사람 아이콘을 눌러 **로그인이 필요한 서비스입니다 → 예**를 거친 뒤, 로그인 화면의 **자동 로그인** 체크를 끄고 첫 계정으로 로그인합니다. 출석을 마치면 메인 화면의 왼쪽 위 전체메뉴를 열어 맨 아래 **설정 → 로그아웃**으로 이동합니다. 로그아웃 버튼을 누른 뒤 별도의 로그아웃 완료 확인 단계 없이 다음 계정 로그인 절차를 바로 시작하며, 신세계 앱이 확인 팝업을 띄우면 확인 버튼을 누르고 진행합니다. 마지막 계정은 출석 후 로그인 상태로 남습니다. 계정별 실패는 결과에 기록하고 다음 계정으로 넘어가되, 로그아웃 버튼을 찾지 못하거나 `자동 로그인 사용` 스위치 상태를 확인할 수 없으면 전체 실행을 중단합니다.

계정 전환 전에 신세계 앱의 **환경설정 → 자동 로그인 사용**이 켜져 있으면 앱이 끄며, 실행 후에도 꺼진 상태로 유지됩니다. 신세계 앱에서 추가 인증을 요구하면 직접 인증할 수 있도록 기다립니다. 계정은 최대 10개까지 기기에 암호화해 저장하며, 비밀번호는 목록에 표시하지 않습니다. 계정 정보 보호를 위해 이 앱의 화면 캡처는 차단됩니다. 실제 신세계 앱 화면에 대한 실기기 검증은 아직 필요합니다.

`v4.7.31`부터는 신세계 로그인 화면의 **자동 로그인** 체크박스도 아이디·비밀번호 입력 전에 해제하고, 로그인 버튼을 누르기 직전 다시 해제 상태를 확인합니다. `v4.7.32`부터는 각 계정의 로그인 진입을 리워드 탭이 아닌 메인 화면의 사람 아이콘으로 통일합니다. 체크 상태를 읽을 수 없거나 끄지 못하면 다른 계정으로 잘못 진행하지 않도록 실패 원인을 알립니다.

`v4.7.33`은 자동출석 시작 시 신세계 앱을 한 번만 실행하고 기존 앱 화면을 앞으로 가져옵니다. 화면 정보가 늦게 표시되어도 앱을 반복해서 재실행하지 않으며, 시작 화면 로딩 중에는 뒤로가기를 누르지 않습니다. 접근성 이벤트가 연속으로 발생해도 화면 전환 대기시간을 지키고 같은 동작이 중복 실행되지 않도록 조정했습니다. 휴대폰이 잠겨 있다면 기존 잠금 해제 절차를 먼저 진행합니다.

## 동작 조건

`v4.9.35`는 로그인 버튼을 누른 뒤 **로봇이 아닙니다** 또는 추가 인증 화면이 나타나면 알림을 띄우고 최대 10분 동안 직접 인증을 기다립니다. 인증 대기 시간은 계정별 2분 제한에서 제외되며, 대기 중에는 다른 계정으로 넘어가거나 앱을 나가지 않습니다. 프라이버시 커튼도 잠시 해제되어 인증 화면을 볼 수 있고, 알림을 누르면 신세계 앱으로 이동합니다. 사용자가 직접 체크하여 체크 완료 상태를 읽을 수 있으면 신세계 앱의 로그인 버튼을 한 번 누르고 출석을 이어갑니다. CAPTCHA 체크박스나 인증 문제 자체는 자동 조작하지 않습니다. 체크 완료 상태를 화면에서 읽을 수 없거나 인증번호·보안문자 등의 인증이면 신세계 앱에서 로그인까지 직접 완료해주세요. 로그인된 화면이 확인되면 자동출석을 이어가며, 인증을 마친 뒤 커튼을 복구합니다.

`v4.8.34`는 신세계 앱 광고의 **오늘은 그만보기**를 체크한 다음 **닫기**를 누르는 기능을 추가합니다. 체크 상태가 표시되는 화면에서는 이미 체크된 항목을 다시 누르지 않습니다. 체크 상태를 제공하지 않는 화면에서는 해당 문구를 한 번 눌러 체크한 뒤 닫습니다. 첫 계정은 이미 로그아웃 상태이면 바로 로그인하며, 계정 사이의 로그아웃은 유지합니다.

- 휴대폰 전원이 켜져 있어야 합니다.
- 계정별 자동 로그인을 사용하려면 이 앱에 신세계 계정 정보가 저장되어 있어야 합니다.
- 화면 잠금이 해제되어 있어야 합니다.
- 삼성 배터리 설정에서 이 앱을 **제한 없음**으로 지정하는 것을 권장합니다.

프라이버시 커튼을 켜면 자동화 중 화면을 검게 가리고 밝기를 낮추며, 완료 후 화면을 다시 끕니다. Android 내부에서는 신세계백화점 앱이 실제로 화면에 열린 상태로 조작됩니다.

자동 로그인 정보는 Android Keystore 키로 암호화하여 휴대폰 내부에만 저장합니다. 소스 코드·APK·GitHub에는 계정 정보를 넣지 않으며 APK에는 인터넷 권한이 없습니다. 로그인 페이지가 변경되거나 추가 인증이 필요하면 자동 로그인을 완료하지 못할 수 있으며, 이 경우 실패 이유를 알립니다. 신세계 앱 화면이나 이벤트 구성이 변경되면 업데이트가 필요할 수 있습니다.

`v1.1.0-fast20`은 최근 앱 카드 제목이 정확히 `신세계`와 일치할 때만 제거합니다. 부분 일치나 `신세계 자동 출석` 카드는 제외하며, 제거 동작이 없을 때도 정확히 확인된 `신세계` 제목의 가로 중심에서만 위쪽 제스처를 실행합니다.

`v1.1.0-result-popup`은 자동 출석의 성공과 실패를 높은 중요도의 결과 알림으로 표시합니다. 실패하면 발견된 문제나 마지막으로 진행하던 단계를 알립니다. 예약 시각의 출석 독촉 알림은 별도 설정으로 유지됩니다. 휴대폰의 알림 권한, 채널 팝업 설정, 방해 금지 모드에 따라 실제 팝업 표시는 제한될 수 있습니다.

`v1.1.1`은 신세계 앱에서 로그인이 필요한 화면이 확인될 때 저장한 계정으로 로그인을 시도하고, 로그인 완료 후 기존 출석 절차를 이어갑니다. 로그인 화면의 입력칸과 버튼을 확인할 수 없거나 추가 인증이 요구되면 실패 알림을 표시합니다.

`v1.1.2`는 신세계 앱의 "로그인이 필요한 서비스" 팝업이 보이면 **예**를 누르고, 팝업이 닫혀 로그인 입력 화면이 나타난 다음 저장된 계정으로 로그인을 시도합니다.

`v1.1.24`는 아이디·비밀번호 입력 후 갱신된 로그인 화면에서 버튼을 다시 찾아 누릅니다.

`v3.7.29`는 출석 성공 또는 실패 후 최근 앱에서 제목이 정확히 `신세계`인 카드만 찾아 제거하고, Android가 제공하는 자기 앱 작업 목록에서 `신세계 자동 출석` 카드도 제거합니다. 다른 앱 작업은 제거하지 않습니다.

## 버전 번호 기준

- 맨 앞 숫자: 기존 설정이나 사용 방식과 호환되지 않는 개편이 있을 때 올립니다. 컴퓨터 연결 방식에서 휴대폰 단독 APK로 전환해 `2`, 메인 화면 개편에서 `3`, 순차 다계정 출석 방식으로 전환한 이번 배포에서 `4`가 되었습니다. 기존 예약 설정과 단일 계정 정보는 이전됩니다.
- 중간 숫자: 기존 설정과 사용 방식을 유지하면서 독립적인 새 기능을 추가할 때 올립니다. GitHub 이력의 화면 상태 복귀(`6ce7a67`), 별도 출석 알림(`3dc1615`), 드래그 잠금 해제 지원(`7344b5d`), 최근 앱 정리(`d0ca496`), 결과 팝업(`89fcc36`), 자동 로그인(`4acbdba`)을 반영해 초기 `1`에서 `7`로 맞췄으며, 광고 당일 숨김 기능으로 `8`, 직접 인증 대기·재개 기능으로 `9`로 올렸습니다. 후속 보완 커밋은 같은 기능으로 묶었습니다.
- 마지막 숫자: 초기 APK 이후 수정된 APK를 배포할 때마다 1씩 올리는 누적 번호입니다. 이번 직접 인증 대기·재개 배포는 `35`입니다. 앞이나 중간 숫자가 바뀌어도 초기화하지 않습니다.

매번 배포 전에 기존 사용 방식과의 호환성, 독립적인 새 기능, 누적 수정 번호를 순서대로 확인해 세 숫자를 결정합니다. APK 내부 `versionCode`는 설치된 앱을 업데이트할 수 있도록 배포마다 별도로 증가시킵니다. 기존 APK 파일은 이전 배포 이력으로 남겨둡니다.

앱 운영 정책에 따라 자동화 이용이 제한될 수 있으므로 본인 계정에서 정책을 확인한 후 사용하세요.
