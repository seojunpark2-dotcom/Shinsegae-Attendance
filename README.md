# Shinsegae Attendance

신세계백화점 앱의 리워드 캘린더 출석을 안드로이드 휴대폰에서 예약 실행하는 개인용 APK입니다.

## 다운로드

- [APK v4.9.44 바로 다운로드](https://github.com/seojunpark2-dotcom/Shinsegae-Attendance/raw/refs/heads/account/releases/shinsegae-auto-attendance-v4.9.44.apk)
- [ZIP v4.9.44 바로 다운로드](https://github.com/seojunpark2-dotcom/Shinsegae-Attendance/raw/refs/heads/account/releases/shinsegae-auto-attendance-v4.9.44.zip) — 브라우저가 APK를 차단할 때 사용

저장소가 비공개인 경우 GitHub에 로그인한 상태에서 링크를 열어야 합니다. ZIP을 받은 경우 압축을 풀고 안의 APK를 설치하세요. 이 버전은 `account` 브랜치에서만 배포하며 `main`은 변경하지 않습니다.

## 설정

1. APK를 휴대폰에 설치합니다.
2. 앱을 열고 알림 권한을 허용합니다.
3. **접근성 권한 열기**에서 `신세계 자동 출석`을 켭니다.
4. **알람 권한 열기**에서 정확한 알람을 허용합니다.
5. 화면 위쪽의 **시간 변경**으로 예약 시각을 정하고, 필요하면 **프라이버시 커튼**을 설정합니다.
6. **매일 자동 출석** 스위치를 켠 뒤 **지금 수동 실행**으로 확인합니다.
7. 결과 알림이 표시되지 않으면 **결과 팝업 알림 설정**에서 알림을 허용하고 팝업 표시를 켭니다. Android 13 이상에서는 앱의 알림 권한도 허용해야 합니다.
8. 메인 화면의 **자동 출석 계정**에서 아이디·비밀번호를 하나씩 저장합니다. 저장된 아이디와 순번이 목록에 표시되며, 같은 아이디를 다시 저장하면 순서를 유지한 채 비밀번호가 변경됩니다. 이전 버전에서 저장한 단일 계정은 첫 번째 계정으로 이전됩니다.

## 여러 계정 순차 출석

계정을 저장하면 예약 또는 수동 실행 시 목록 순서대로 처리합니다. 첫 계정은 메인 화면의 로그인 진입부터 시작하며, 이미 로그아웃 상태라면 설정 화면을 방문하지 않습니다. 전날 마지막 계정 등이 남아 있어 로그인된 마이페이지가 나타나는 경우에만 로그아웃합니다. 신세계 앱 메인 화면의 오른쪽 아래 사람 아이콘을 눌러 **로그인이 필요한 서비스입니다 → 예**를 거친 뒤, 로그인 화면의 **자동 로그인** 체크를 끄고 첫 계정으로 로그인합니다. 출석을 마치면 리워드 캘린더 페이지의 오른쪽 아래 줄 세 개 버튼으로 전체메뉴를 바로 열고, 맨 아래 **설정 → 로그아웃**으로 이동합니다. 로그아웃 버튼을 누른 뒤 별도의 로그아웃 완료 확인 단계 없이 다음 계정 로그인 절차를 바로 시작하며, 신세계 앱이 확인 팝업을 띄우면 확인 버튼을 누르고 진행합니다. 마지막 계정은 출석 후 로그인 상태로 남습니다. 계정별 실패는 결과에 기록하고 다음 계정으로 넘어가되, 로그아웃 버튼을 찾지 못하거나 `자동 로그인 사용` 스위치 상태를 확인할 수 없으면 전체 실행을 중단합니다.

계정 전환 전에 신세계 앱의 **환경설정 → 자동 로그인 사용**이 켜져 있으면 앱이 끄며, 실행 후에도 꺼진 상태로 유지됩니다. 신세계 앱에서 추가 인증을 요구하면 직접 인증할 수 있도록 기다립니다. 계정은 최대 10개까지 기기에 암호화해 저장하며, 비밀번호는 목록에 표시하지 않습니다. 계정 정보 보호를 위해 이 앱의 화면 캡처는 차단됩니다. 실제 신세계 앱 화면에 대한 실기기 검증은 아직 필요합니다.

`v4.7.31`부터는 신세계 로그인 화면의 **자동 로그인** 체크박스도 아이디·비밀번호 입력 전에 해제하고, 로그인 버튼을 누르기 직전 다시 해제 상태를 확인합니다. `v4.7.32`부터는 각 계정의 로그인 진입을 리워드 탭이 아닌 메인 화면의 사람 아이콘으로 통일합니다. 체크 상태를 읽을 수 없거나 끄지 못하면 다른 계정으로 잘못 진행하지 않도록 실패 원인을 알립니다.

`v4.7.33`은 자동출석 시작 시 신세계 앱을 한 번만 실행하고 기존 앱 화면을 앞으로 가져옵니다. 화면 정보가 늦게 표시되어도 앱을 반복해서 재실행하지 않으며, 시작 화면 로딩 중에는 뒤로가기를 누르지 않습니다. 접근성 이벤트가 연속으로 발생해도 화면 전환 대기시간을 지키고 같은 동작이 중복 실행되지 않도록 조정했습니다. 휴대폰이 잠겨 있다면 기존 잠금 해제 절차를 먼저 진행합니다.

## 동작 조건

`v4.9.44`는 로그인 성공 후 마이페이지에서 홈 버튼을 누르던 동작을 제거했습니다. 로그인 직후 화면을 유지한 채 우측 아래 줄 세 개 버튼을 즉시 누르고, **전체메뉴 → 참여한 이벤트 → 리워드 캘린더 → 리워드 받으러 가기**를 진행합니다. 메뉴 터치가 반영되지 않으면 메인 화면뿐 아니라 로그인된 마이페이지에서도 메뉴 버튼을 재시도합니다. 직접 인증 후 로그인 성공 시에도 같은 경로를 사용하며, 이후 출석 및 계정 전환은 유지합니다. 실기기 검증은 필요합니다.

`v4.9.43`부터 각 계정 로그인 후 **우측 아래 줄 세 개 → 전체메뉴 → 참여한 이벤트 → 리워드 캘린더 → 리워드 받으러 가기** 경로를 사용합니다. R 월렛 진입과 가로 카드 슬라이드는 사용하지 않습니다. 캘린더 항목이 바로 보이면 즉시 누르며, 목록이 길면 참여한 이벤트 목록 안에서만 제한적으로 세로 스크롤합니다. 목록·캘린더가 열리지 않으면 단계별 원인을 알립니다. 이후의 짧은 캘린더 스크롤, 출석 결과 확인, 설정·로그아웃 및 다음 계정 진행은 유지합니다. 저장된 계정과 사용자 설정을 바꾸지 않는 외부 앱 경로 대응 수정이므로 major/minor는 유지하고 revision만 증가시켰습니다. 기기에서 새 경로의 동작 검증은 필요합니다.

`v4.9.42`는 로그인 후 메인 화면이 남아 있는데 월렛 카드 스크롤을 실행하던 분기 순서를 수정했습니다. 하단 R·월렛·리워드 버튼의 실제 표시 위치를 우선 터치하고, 버튼이 이름 없이 표시되는 화면은 MY SHINSEGAE 하단 탭의 높이에 맞춰 R 위치를 누릅니다. 터치 후 750ms의 전환 시간을 두며, 메인 화면이 남아 있으면 스크롤 대신 R 버튼을 최대 6회 누릅니다. 별도의 월렛 확인 페이지나 확인 단계를 추가하지 않습니다. 진입 시도가 소진되면 메인 배너를 스크롤하지 않고 실패 원인을 알립니다. 진입 재시도 횟수는 계정마다 초기화합니다. 실제 모든 계정의 성공 여부는 기기와 앱·서버 동작에 따라 달라집니다.

`v4.9.41`은 설정·로그아웃 구간을 유지하고 앱 실행, 광고 닫기, 로그인 입력 및 제출, 리워드 이동과 출석 결과 확인의 고정 대기를 단축했습니다. 화면 이벤트 확인은 250ms에서 120ms로, 일반 재확인은 650ms에서 400ms로 줄였습니다. 리워드 이동은 900ms에서 450ms로, 출석 결과 최초 확인은 2200ms에서 650ms로 줄였으며 결과 대기 중에는 출석 버튼을 중복 누르지 않습니다. 로그인 재시도 횟수를 늘려 기존의 약 16초 확인 여유를 유지합니다. 직접 인증 대기 최대 10분과 계정별 제한은 그대로입니다. 실제 완료 시간은 신세계 앱과 서버 응답 속도에 따라 달라집니다.

`v4.9.40`은 전체메뉴 하단 설정 항목의 화면 표시 동작을 지원하면 설정 위치로 바로 이동합니다. 지원하지 않으면 목록의 마지막 항목으로 직접 이동을 시도하고, 그마저 지원하지 않는 화면은 본문에서 90ms의 빠르고 긴 스와이프로 내려갑니다. 스크롤 후 확인 간격은 850ms에서 350ms로 줄였습니다. 설정이 보이면 즉시 누르며, 한 번에 도달하지 못하는 기기에서는 최대 12회 보완 동작을 수행합니다. 외부 앱이 직접 이동 기능을 제공하지 않으면 한 번의 스크롤로 최하단에 도달하는 것은 보장하지 않습니다.

`v4.9.35`부터 로그인 버튼을 누른 뒤 **로봇이 아닙니다** 또는 추가 인증 화면이 나타나면 최대 10분 동안 직접 인증을 기다립니다. `v4.9.37`에서는 체크박스가 처음 감지될 때 팝업 알림 없이 **1.5초 진동을 한 번** 울립니다. 이미지 인증 화면이 나타날 때까지 기다리지 않고 로그인 후 대기 중에도 체크박스를 관찰합니다. 휴대폰의 진동·방해 금지 설정에 따라 진동이 제한될 수 있습니다. 인증 대기 시간은 계정별 2분 제한에서 제외되며, 대기 중에는 다른 계정으로 넘어가거나 앱을 나가지 않습니다. 프라이버시 커튼도 잠시 해제되어 인증 화면을 볼 수 있습니다. 사용자가 직접 체크한 뒤 Android 체크 속성뿐 아니라 WebView의 체크됨·확인됨 상태 설명과 명시적인 인증 완료 문구를 읽어 완료를 확인합니다. 한 번 확인한 완료 상태를 유지하며 화면 배치가 바뀌어도 현재 로그인 제출 버튼을 다시 찾아 중앙을 눌러 출석을 이어갑니다. 실제로 체크 해제 상태가 확인되면 완료 기록을 취소하고 다시 기다립니다. CAPTCHA 체크박스나 인증 문제 자체는 자동 조작하지 않습니다. 화면이 완료 상태를 제공하지 않거나 인증번호·보안문자 등의 인증이면 신세계 앱에서 로그인까지 직접 완료해주세요. 로그인된 화면이 확인되면 자동출석을 이어가며, 인증을 마친 뒤 커튼을 복구합니다.

`v4.8.34`는 신세계 앱 광고의 **오늘은 그만보기**를 체크한 다음 **닫기**를 누르는 기능을 추가합니다. 체크 상태가 표시되는 화면에서는 이미 체크된 항목을 다시 누르지 않습니다. 체크 상태를 제공하지 않는 화면에서는 해당 문구를 한 번 눌러 체크한 뒤 닫습니다. 첫 계정은 이미 로그아웃 상태이면 바로 로그인하며, 계정 사이의 로그아웃은 유지합니다.

- 휴대폰 전원이 켜져 있어야 합니다.
- 계정별 자동 로그인을 사용하려면 이 앱에 신세계 계정 정보가 저장되어 있어야 합니다.
- 화면 잠금이 해제되어 있어야 합니다.
- 삼성 배터리 설정에서 이 앱을 **제한 없음**으로 지정하는 것을 권장합니다.

프라이버시 커튼을 켜면 자동화 중 화면을 검게 가리고 밝기를 낮추며, 완료 후 화면을 다시 끕니다. Android 내부에서는 신세계백화점 앱이 실제로 화면에 열린 상태로 조작됩니다.

자동 로그인 정보는 Android Keystore 키로 암호화하여 휴대폰 내부에만 저장합니다. 소스 코드·APK·GitHub에는 계정 정보를 넣지 않으며 APK에는 인터넷 권한이 없습니다. 로그인 페이지가 변경되거나 추가 인증이 필요하면 자동 로그인을 완료하지 못할 수 있으며, 이 경우 실패 이유를 알립니다. 신세계 앱 화면이나 이벤트 구성이 변경되면 업데이트가 필요할 수 있습니다.

`v1.1.0-fast20`은 최근 앱 카드 제목이 정확히 `신세계`와 일치할 때만 제거합니다. 부분 일치나 `신세계 자동 출석` 카드는 제외하며, 제거 동작이 없을 때도 정확히 확인된 `신세계` 제목의 가로 중심에서만 위쪽 제스처를 실행합니다.

`v1.1.0-result-popup`은 자동 출석의 성공과 실패를 높은 중요도의 결과 알림으로 표시합니다. 실패하면 발견된 문제나 마지막으로 진행하던 단계를 알립니다. 예약 시각의 출석 독촉 알림은 별도 설정으로 유지됩니다. 휴대폰의 알림 권한, 채널 팝업 설정, 방해 금지 모드에 따라 실제 팝업 표시는 제한될 수 있습니다.

`v1.1.1`은 신세계 앱에서 로그인이 필요한 화면이 확인될 때 저장한 계정으로 로그인을 시도하고, 로그인 완료 후 기존 출석 절차를 이어갑니다. 로그인 화면의 입력칸과 버튼을 확인할 수 없거나 추가 인증이 요구되면 실패 알림을 표시합니다.

`v1.1.2`는 신세계 앱의 "로그인이 필요한 서비스" 팝업이 보이면 **예**를 누르고, 팝업이 닫혀 로그인 입력 화면이 나타난 다음 저장된 계정으로 로그인을 시도합니다.

`v1.1.24`는 아이디·비밀번호 입력 후 갱신된 로그인 화면에서 버튼을 다시 찾아 누릅니다.

## 버전 번호 기준
